A verificar se o servidor está configurado…

Esta aplicação precisa de ser executada num servidor Node.js com a variável secreta HF_TOKEN. Nunca coloques o token neste HTML nem o partilhes com ninguém.

Para gerar vídeo, a conta precisa de ter acesso a um provedor compatível e créditos disponíveis. O botão tentará a API; se o modelo/provedor não estiver disponível, mostrará o erro.
